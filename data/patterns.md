# Шаблоны: что кодировать к каждой эпохе

Собрано `tools/patterns.py` по графу рецептов. Предмет стоит в той эпохе, где он нужен впервые: к этому моменту его шаблон должен быть закодирован. Повторно в следующих эпохах он не пишется. Предметы без перевода показаны по внутреннему имени.

## Чем кодировать

| Вид | Чем кодировать и где выполняется |
|---|---|
| Крафт 3x3 | терминал шаблонов, молекулярный или улучшенный сборщик |
| Крафт 9x9 | большой сборщик X9 |
| Сингулярности | нейтронный кодировщик, нейтрониевый сборщик |
| Синтез | внеземной дракониевый кодировщик, сборщик синтеза |
| Сборочный стол | лазерный кодировщик, сборщик сборочного стола |
| Обработка | терминал шаблонов, интерфейс у механизма |
